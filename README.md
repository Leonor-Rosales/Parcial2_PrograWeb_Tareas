# Dashboard de tareas — Django

Aplicación local para las tareas de un estudiante.

## Archivos principales

- `tareas/models.py`: modelo y restricción de estados en la base de datos.
- `tareas/views.py`: consultas, filtro y actualización limitada.
- `config/urls.py`: rutas HTTP.
- `tareas/templates/tareas/dashboard.html`: interfaz que consume la API con fetch.
- `tareas/migrations/`: estructura versionada de la base de datos.
- `tareas/tests.py`: pruebas de contrato, persistencia, errores y CSRF.
